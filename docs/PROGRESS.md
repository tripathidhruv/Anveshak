## 2026-09-25 (backend, cont'd) · Dhruv + Claude · Task 6 landed after catching a real fan-out taint bug
**Did:** Task 6 (causal FIFO tracer + conservation invariant + chain registry) — the single most correctness-critical task in the plan, since KAIZEN's whole pitch is that competitors get exactly this logic wrong. Took 2 fix passes, both catching real bugs, not nitpicks:
1. **Critical:** the first implementation capped each sibling branch's taint independently (`min(taint, branch_amount)` per branch with no shared budget), so a wallet that fans out into multiple outgoing transfers could report *more* total downstream taint than it ever actually held — e.g. taint=150 split across three 100-unit branches would claim 100+100+100=300 traced, not ≤150.
